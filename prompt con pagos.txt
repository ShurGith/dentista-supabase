Actúa como un equipo senior de producto, arquitectura de software, UX/UI y desarrollo full-stack.

Crea una aplicación web y móvil para la gestión integral de citas de una clínica odontológica llamada [NOMBRE_CLÍNICA].

El sistema debe ser profesional, seguro, escalable y listo para funcionar primero en local y después desplegarse en un servidor online.

Stack obligatorio:
- Frontend web: React + Vite + TypeScript + Tailwind CSS + shadcn/ui.
- App móvil: React Native con Expo, reutilizando la máxima lógica posible con el backend.
- Backend: Node.js con Express o NestJS, TypeScript y arquitectura modular.
- Base de datos y autenticación: Supabase (PostgreSQL, Auth, Storage, Row Level Security y Edge Functions si son necesarias).
- Integración WhatsApp: Wawp (https://wawp.net/en), mediante su API o webhooks. Debe permitir enviar mensajes, recibir mensajes entrantes y sincronizar conversaciones.
- Estado global: Zustand o React Query.
- Validaciones: Zod.
- ORM/acceso a datos: Supabase JS Client; usar migraciones SQL versionadas.
- Testing: Vitest/Jest y Playwright para flujos críticos.
- Documentación: README con instalación local, variables de entorno, migraciones, despliegue y configuración de Wawp.

OBJETIVO DE NEGOCIO

La clínica necesita digitalizar la captación de pacientes, la reserva de citas, la gestión del personal odontológico, la comunicación por WhatsApp y la administración general.

Debe incluir:
1. Una web pública muy profesional, tipo landing page corporativa de clínica dental.
2. Un panel de administración interno tipo CRM.
3. Una app móvil para pacientes y/o personal de la clínica.
4. Automatizaciones de WhatsApp para confirmaciones, recordatorios, cambios de cita y seguimiento.
5. Un sistema de bandeja de conversaciones WhatsApp con cada paciente.

PARTE 2 — PANEL ADMINISTRATIVO / CRM

Crea un panel privado para administradores, recepción y dentistas.

Roles y permisos:
- Superadmin: acceso total, configuración, usuarios, roles, facturación interna y auditoría.
- Administrador/recepción: gestión de pacientes, agenda, citas, mensajes, configuración operativa.
- Dentista/profesional: acceso a su agenda, pacientes asignados, historial clínico y conversaciones relacionadas.
- Recepcionista limitado: gestión de citas y comunicación, sin acceso a datos clínicos sensibles salvo permiso explícito.

Módulos obligatorios:

1. Dashboard
- Citas de hoy, próximas citas, pacientes nuevos, cancelaciones, ausencias, ingresos estimados y ocupación por profesional.
- Gráficos de citas por día, semana, mes, servicio y profesional.
- Alertas: citas sin confirmar, pacientes pendientes de respuesta, huecos en agenda y recordatorios fallidos.

2. Gestión de pacientes
- CRUD completo de pacientes.
- Datos: nombre, apellidos, DNI/NIE opcional, fecha de nacimiento, teléfono, email, dirección, notas, tags, fuente de captación, consentimientos y estado.
- Historial clínico básico: alergias, medicación, antecedentes, tratamientos realizados, presupuesto, documentos y archivos.
- Búsqueda avanzada, filtros, exportación CSV y auditoría de cambios.
- Cumplimiento RGPD: consentimientos, derecho de acceso, supresión/anonimización y registro de accesos a datos sensibles.

3. Gestión de dentistas y personal
- CRUD de profesionales.
- Especialidad, horario laboral, días libres, vacaciones, servicios que realiza y color en calendario.
- Configuración de duración por tipo de cita.
- Gestión de usuarios, roles, permisos y estados activo/inactivo.

4. Agenda y citas
- Calendario diario, semanal y mensual.
- Vista por clínica, profesional, sala/consultorio y servicio.
- Crear, editar, reprogramar, confirmar, cancelar y marcar como completada una cita.
- Detección automática de solapamientos.
- Estados de cita: pendiente, confirmada, en espera, completada, cancelada por paciente, cancelada por clínica, no asistida.
- Motivos de cancelación y reprogramación.
- Reserva con validación de disponibilidad en tiempo real.
- Bloqueos de agenda, festivos y excepciones.
- Opción de citas recurrentes o de seguimiento.

5. WhatsApp y comunicaciones
- Integración con Wawp para:
  - Enviar mensajes individuales desde la ficha del paciente.
  - Enviar plantillas con variables: nombre, fecha, hora, profesional, clínica, enlace de confirmación y enlace de cancelación.
  - Enviar recordatorios automáticos antes de la cita, con tiempo configurable.
  - Enviar confirmación al crear cita.
  - Enviar aviso al reprogramar o cancelar.
  - Enviar mensaje post-cita de satisfacción o seguimiento.
  - Enviar campañas o mensajes masivos segmentados, con control anti-spam.
- Bandeja de conversaciones WhatsApp:
  - Listado de chats por paciente.
  - Historial completo de mensajes enviados y recibidos.
  - Estados: enviado, entregado, leído y fallido.
  - Asignación de conversación a un miembro del equipo.
  - Etiquetas, notas internas y búsqueda.
  - Respuesta manual desde el panel.
  - Webhook para recibir mensajes entrantes de Wawp en tiempo real.
  - Prevención de duplicados y reintentos seguros.
- Registro de todos los envíos para auditoría.

6. Configuración general
- Datos de la clínica: nombre, logo, dirección, teléfono, email, horarios, redes sociales, colores y textos de la web.
- Servicios dentales: nombre, descripción, duración, precio, color, activo/inactivo.
- Profesionales y asignación de servicios.
- Horarios y reglas de agenda.
- Plantillas de WhatsApp editables.
- Configuración de Wawp: API key/token, número WhatsApp, webhook, eventos y entorno sandbox/producción.
- Configuración de recordatorios: 24 horas antes, 2 horas antes, etc.
- Gestión de usuarios, roles y permisos.
- Registro de auditoría.

PARTE 6 — FLUJOS CLAVE

Implementa y documenta estos flujos:

1. Reserva desde la web
- Paciente selecciona servicio, profesional, fecha y hora.
- El sistema valida disponibilidad.
- Crea o vincula el paciente por teléfono/email.
- Crea la cita en estado pendiente.
- Envía confirmación por WhatsApp usando Wawp.
- Registra el envío y actualiza el estado del mensaje.

2. Recordatorio automático
- Job programado revisa citas próximas.
- Envía recordatorio según la configuración.
- Evita duplicados.
- Permite confirmar, cancelar o solicitar cambio desde un enlace seguro.

3. Confirmación o cancelación por WhatsApp
- El paciente responde o pulsa un enlace.
- El webhook de Wawp actualiza la cita.
- El personal ve el cambio en el CRM y la agenda.

4. Conversación WhatsApp
- El paciente escribe al número de la clínica.
- Wawp envía el webhook.
- El backend guarda el mensaje, lo asocia al paciente y actualiza la conversación.
- El equipo responde desde el CRM.
- El mensaje sale por Wawp y se guarda con su estado.

5. Reprogramación
- Recepción o paciente solicita cambio.
- El sistema valida nueva disponibilidad.
- Actualiza la cita, guarda historial y envía aviso por WhatsApp.
